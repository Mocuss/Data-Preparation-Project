# Data-Preparation-Project
Singapore Tourism Analysis <br>
The objective is to develop data-driven insights and actionable recommendations
for a real-world issue, using public datasets and the CRISP-DM methodology. <br>

## Data Sets:
All datasets are taken from Singstat.gov.sg. <br>
1. Tourist Country of Arrival: https://tablebuilder.singstat.gov.sg/table/TS/M550001 <br>
2. Tourist Receipt and Spendings: https://tablebuilder.singstat.gov.sg/table/TS/M550371# <br>
3. Tourist Demographics: https://tablebuilder.singstat.gov.sg/table/TS/M550241 <br>
4. Hotel Statistics:  https://tablebuilder.singstat.gov.sg/table/TS/M550081 <br>

## 🛠 Tools & Technologies
Google Colab: Data cleaning, transformation, and analysis
Power BI: Interactive dashboard and data visualization
CRISP-DM: Structured data mining process

##Items in repository:
Raw Data: Contains the main 4 datasets used for this project
Processed Data: All cleaned data from data preparation file
Data preparation file: All google colab code to clean datasets
Dashboards: Contains all dashboards made for analysis
Report and Presentation: Final Deliverables for project
